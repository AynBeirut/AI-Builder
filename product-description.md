# AI Builder

AI Builder is an AI-assisted website builder for entrepreneurs, freelancers and
small agencies. Its documented direction includes conversational code generation,
live previews, project management, provider selection, credits and deployment.
The roadmap is not a claim that every feature is complete.

The current application manifest declares Next.js 16, React 19 and TypeScript,
with Prisma, NextAuth, AI-provider SDKs, Sandpack and Monaco dependencies. Older
version references in the README describe the earlier project baseline.

For implementation details, start with [ai-builder/README.md](ai-builder/README.md).
